## Prerequisites

Install the pi cli. [more info](https://pi.dev)

Install a needed pi extension: `pi-msg` [more info](https://github.com/m7l5/pi-msg)

```sh
pi install git:github.com/m7l5/pi-msg
```

## Local development

```sh
npm install
npm run package-install
```
