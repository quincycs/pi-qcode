i'd like another kind of typeahead / autocomplete just like in plan15.md but initiated by a different trigger '#'.

Instead of files it will be from a customizable list of options that the user can set in settings.

Settings should allow the user to add , edit, and delete options from the list.

The setting should be for # autocomplete options. The user should put in the '#command' that will be searched for in the text, and then the final value that will be inserted when the user selects that option.

For example, someone could setup the option '#c' with the value 'continue' and then when they type '#c' in the text, the autocomplete option will show with the title '#c' and subtitle 'continue'. If they select that option, it will replace their typed '#c' with 'continue' in the text.
